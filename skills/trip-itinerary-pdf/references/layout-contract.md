# Layout Contract

- Cover: portrait, concise title, dates, travelers, transport, and route highlights.
- Route poster: one landscape page using the approved high-resolution PNG.
- Summary: landscape when the itinerary contains a wide table under a heading containing `行程汇总` or `Trip summary`.
- Detailed itinerary: portrait, each daily H3 starts a new page when practical.
- Footer: trip title plus current and total page number, kept inside page margins.
- Temporary HTML and preview PNGs stay inside the trip project's `tmp/` directory.
